# Host.shared · module.md

> 客户端共享资源子模块（`HostCode/shared/`）。分层定位：**表现层 · 共享冷资源（纯只读）**。主题色板 / UI 贴图 / 干员展示元数据是跨多个表现层模块复用的稳定资源，独立成模块以避免循环依赖。

## 边界

**本模块负责**：
- **主题色板**：`theme`——全 HUD / 主菜单 / 仓库共用的颜色常量（`BG_DEEP` / `ACCENT_CYAN` / `PANEL_BG` / `TEXT_WHITE` / `ACCENT_AMBER` 等），集中视觉身份，避免硬编码 RGB 漂移。
- **干员展示元数据**：`operator::meta`——把 `operator_id` 映射为展示名 / 元素配色 / 技能名（4 元素母板）；`meta(id)` 越界安全取默认。
- **UI 贴图资源**：`ui::assets`——`UiAssets`（当前仅装备页图标 `settings.png`）与就绪标记；`init_ui_assets` 启动加载、`refresh_ui_ready` 每帧刷新。

**本模块不负责**（明确划出）：
- **不含**任何战力/判定数据——弹道、技能、元素反应一律服务端按 `operator_id` 裁决，本模块只画色与名。
- **不持**任何可变状态——除 `UiAssets` 的就绪标记外，全为只读常量与查表。
- **不构建** UI——面板布局归 `menu` / `hud`。

## 数据所有权

| 数据 | 类型 | 是否可变 | 谁可写 |
|---|---|---|---|
| 主题色板 / 干员母板 | `const` / `&'static` | 只读 | 无（编译期常量） |
| UI 贴图就绪态 | `UiAssets` | 可变 | 仅 `shared::ui::assets` |

> **所有权原则**：稳定的展示母板以编译期常量提供；贴图句柄与就绪态由本模块独占，其余模块只读消费。

## 接口

| 接口 | 形式 | 契约 | 兼容性承诺 |
|---|---|---|---|
| `theme::*` | 常量 | 全局色板 | 表现层内部，改名影响全部 UI 模块 |
| `operator::meta::meta(id)` | 函数 | `operator_id` → 展示元数据 | 只读查表 |
| `OPERATORS` | 常量 | 4 元素展示母板 | 与服务端 `roster()` 视觉一致（顺序对齐） |
| `init_ui_assets` / `refresh_ui_ready` | 系统 | 贴图加载与就绪刷新 | `Startup` / 常驻 `Update` |

## 成熟度

**L1（内部稳定：crate 内可依赖）** —— 依据：`shared` 是全局只读冷资源，被全部表现层模块依赖；无对外契约。

- 破坏性变更纪律：须写 ADR + 1 名 reviewer。
- 稳定性：色板与母板为编译期常量，改动只影响观感，不影响任何判定。
